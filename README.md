# Mysql-ecommerce-analysis-project
## Project Overview

This project analyzes e-commerce sales performance, customer behavior, marketing effectiveness, and product returns using MySQL and Power BI.

The project includes:
- Executive Sales Dashboard
- Customer Analytics Dashboard
- Marketing & Returns Analysis Dashboard

## Tools Used

- MySQL
- Power BI
- DAX
- Data Modeling
- GitHub

## Key Business Insights

- Technology generated the highest revenue among all product categories.
- Retail Partner and Website channels contributed the most revenue.
- Home Office customers generated the highest customer revenue.
- Africa emerged as the strongest-performing region.
- Return rate remained low at 5.07%.
- Marketing spend of 441.94K generated a ROAS of 48.58.
